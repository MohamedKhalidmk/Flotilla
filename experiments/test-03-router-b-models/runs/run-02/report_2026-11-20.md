and [table.csv](../../table.csv)).

  ([router_b.json](router/router_b_modernbert/router_b.json) has every epoch).

  32K 0.867 vs Qwen 0.697, test 02). A fixed long-input rule was left as a separate, open decision; test 04's strategy
  routers on LongMemEval replaced it.
- **Labels:** the real Flotilla loop (`flotilla/label_loop.py`) over the 4,760 clean pool questions (leakage-checked
  against every test set, small-test items included), graded from the pool with code fences stripped.
